# 世界杯数据门户网站 —— 功能清单与数据库表设计

> 本文档是「需求文档」与「设计文档」的底稿,内容为:功能划分(前台/后台)+ 数据库表清单 + 表间关系。
> 字段级建表设计(字段、类型、索引、约束)见配套文档《数据库表详细设计.md》。
> 技术栈:PHP + MySQL,MVC 结构。主题:世界杯。

---

## 一、项目概述

- **网站定位**:世界杯主题的数据门户,兼顾社区留言。用户可浏览球队 / 球员 / 比赛数据,并对各实体留言;管理员登录后可增删改数据、发布信息、管理留言。
- **数据范围**:覆盖近 40 年(约 1986~2026)历届世界杯,采用**「届次维度」建模**——把"稳定身份"(球队、球员)与"每届变化的事实"(小组、教练、排名、球衣号)拆开存放。
- **形态**:前台(展示 + 留言)+ 后台(管理),前后台分离。
- **留言方案**:采用「实体下留言(评论式)」——一张 `comment` 表,通过 `target_type` 挂载到球队 / 球员 / 比赛 / 资讯 / 届次等任意实体上。

## 二、功能清单

### 2.3 动态图形展示(加分项,数据来源现成)

| 图形 | 数据来源 | 图表类型(建议 ECharts) |

## 三、数据库表一览

> 共 14 张。字段级设计(字段、类型、索引、约束)见《数据库表详细设计.md》。

**多届建模思路(维度建模)**:`team`、`player` 是「维度表」(身份稳定、跨届不变);`tournament_team`、`squad` 是「届次关联表」(承载每届都变的事实,如小组、教练、排名、球衣号);`game`、`goal` 是「事实表」(挂 `tournament_id` 区分届次)。

### 3.1 核心表(14 张,必做,已满足 >10 张)

| 表名 | 用途 |
|---|---|
| `tournament` | 届次(每届世界杯一行,1986~2026) |
| `team` | 球队 / 国家队(身份稳定) |
| `player` | 球员(身份稳定) |
| `tournament_team` | 参赛队伍(某届某队的小组 / 教练 / 排名) |
| `squad` | 参赛名单(某球员在某届某队的球衣号) |
| `game` | 比赛(原名 match;因 match 是 PHP 8 保留字而改名) |
| `goal` | 进球记录 |
| `comment` | 留言(多态挂载) |
| `user` | 用户(普通用户 + 管理员共用) |
| `member` | 团队成员 |
| `team_info` | 团队介绍(单例表) |
| `work` | 作业文件 |
| `news` | 资讯 / 公告发布(内容发布) |
| `comment_like` | 留言点赞 |

## 四、表间关系(ER 简述)

```
tournament 1 ── N tournament_team N ── 1 team
tournament 1 ── N squad            ├── 1 team
                                    └── 1 player
tournament 1 ── N game
team       1 ── N game        (主/客队)
game       1 ── N goal
team       1 ── N goal        (进球归属队;乌龙球记受益方,不是乌龙球员所在队)
player     1 ── N goal        (player_id 进球者 / assist_player_id 助攻者)

comment  ——多态挂载——► team / player / game / news / tournament
comment  1 ── N comment       (parent_id 回复)
user     1 ── N comment
user     1 ── N comment_like N ── 1 comment

member / team_info / work / news 为相对独立的管理实体(管理员并入 user)
```
